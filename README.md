# ESE 123 Lab 5: Capacitors & the Oscilloscope

An interactive, animated walkthrough of ESE 123 Laboratory 5 for students:

1. Reading the scope screen by counting boxes
2. Three ways to measure (counting boxes, cursors, automatic measurements), plus Avg-FS vs N-Cycle
3. What a capacitor does: X_C = 1/(2πfC) and RC charging
4. Frequency sweep of the RC filter from 3 kHz to 1 Hz with a live two-channel scope, Autoscale limits, and theory values
5. Building the circuit board part by part, with bypass capacitors explained
6. Powering up and measuring DC with the DMM (voltage divider)

Live page: https://cad281.github.io/ese123-lab5/

Everything is in one self-contained `index.html` (fonts from Google Fonts).
